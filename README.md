
# Finazly App

Finanzly iss a comprehensive app designed to help you efficiently manage multiple accounts and funds without the need for a real bank account. Whether you're a developer testing financial software or just need a sandbox environment for simulations, this app provides an intuitive interface to create, monitor, and control your funds seamlessly. Easily track balances, transfer funds, and generate transaction histories, all within a secure and user-friendly platform.

- Manage Accounts
- Create Accounts
- Manage account funds
- Fund History
- Expenses and income
